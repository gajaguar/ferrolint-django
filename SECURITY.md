# Security

## Supported versions

The latest release receives security fixes. Older releases are not patched;
pin the version you install if you need a frozen target.

## Reporting a vulnerability

Report vulnerabilities privately by email to
<dev@gajaguar.com>, or through GitHub's private vulnerability reporting on
this repository. Do not open a public GitHub issue, pull request, or
discussion for security reports.

A maintainer will acknowledge receipt within a few working days and follow
up with a fix or a status update. Timelines depend on severity and
reproducer quality; the project has no guaranteed response window.
